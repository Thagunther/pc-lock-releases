# PC Lock downloads

**PC Lock** locks your Windows PC when you walk away with your Android phone, using the phone's Bluetooth signal.

| Download | For |
|---|---|
| `PC_Lock.exe` | Windows 10/11 (tray app; no installer needed) |
| `PC_Lock_Key.apk` | Android 8 and later (the phone app; includes a home screen widget) |

Get them from the [latest release](https://github.com/Thagunther/pc-lock-releases/releases/latest).
Both apps check this page for updates. `SHA256SUMS.txt` lists the checksums of each release.
